# Admin Niayesh

وب‌سایت فارسی و راست‌چین برای معرفی خدمات مدیریت پیج اینستاگرام، سناریونویسی و تولید محتوا.

## فناوری‌ها
- Next.js App Router
- React و TypeScript
- CSS واکنش‌گرا با پشتیبانی RTL
- GitHub Actions برای بررسی کیفیت کد

## اجرای محلی
Node.js نسخه 22 یا جدیدتر پیشنهاد می‌شود.

```bash
npm install
npm run dev
```

برای بررسی پیش از انتشار:
```bash
npm run typecheck
npm run lint
npm run build
```

## پیش از انتشار عمومی
- نمونه‌های بخش نمونه‌کار فعلاً گرافیکی و نمایشی هستند؛ آن‌ها را با نمونه‌کارهای واقعی جایگزین کنید.
- اطلاعات خدمات، متن‌ها و لینک اینستاگرام را بازبینی کنید.
- این نسخه وب‌سایت معرفی خدمات است و فعلاً فرم ارسال اطلاعات یا پنل مدیریت ندارد.
